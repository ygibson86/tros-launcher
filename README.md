# TROS - Launcher

Десктопный лаунчер для Windows на Tauri 2 (Rust + WebView2).  
Позволяет создавать группы и кнопки для запуска программ, скриптов и команд.

## Возможности

- Запуск программ и скриптов (CMD, PowerShell)
- Режим редактирования с защитой паролем
- Экспорт и импорт конфигурации (JSON)
- Группировка кнопок
- Поиск по кнопкам
- Подтверждение удаления
- Перемещение кнопок и групп с помощью стрелок
- Автоматическое переключение фокуса на запущенное окно

## Сборка

Установите [Tauri CLI](https://tauri.app/start/prerequisites/) и выполните:

```bash
cargo tauri build
```
Готовый .exe появится в src-tauri/target/release/launcher.exe
