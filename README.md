# Tros Launcher

Десктопный лаунчер для Windows на Tauri 2 (Rust + WebView2).  
Позволяет создавать группы и кнопки для запуска программ, скриптов и команд. Конфигурация хранится в JSON-файле рядом с EXE, что делает приложение портативным.

## Основные возможности

- Запуск любых исполняемых файлов (.exe, .bat, .cmd) и PowerShell-скриптов.
- Поддержка консольных команд с паузой после выполнения (окно не закрывается).
- Возможность запуска с правами администратора (UAC-запрос).
- Группировка кнопок по категориям для удобства.
- Режим редактирования, защищённый паролем (SHA-256 хеш).
- Экспорт и импорт всей конфигурации (полезно для бэкапа или переноса).
- Поиск по названиям и командам кнопок.
- Дублирование кнопок и их перемещение внутри группы с помощью стрелок.
- Автоматический захват фокуса на окно запущенного приложения (через WinAPI).
- Полностью портативный – один EXE и файл config.json рядом.

## Сборка из исходников

Для самостоятельной сборки вам потребуется:

- Windows 10/11 (x64)
- Rust (установить с rustup.rs, выбрав стабильный MSVC-тулчейн)
- Visual Studio Build Tools (или полная Visual Studio) с компонентом «Desktop development with C++»
- WebView2 Runtime (обычно уже есть в системе, если нет – скачать с сайта Microsoft)
- Tauri CLI версии 2 (устанавливается через cargo install tauri-cli --version "^2")

Пошаговая инструкция:

1. Клонируйте репозиторий:
   git clone https://github.com/ygibson86/tros-launcher.git
   cd tros-launcher

2. Выполните сборку:
   cargo tauri build

3. Готовый исполняемый файл появится по пути:
   src-tauri/target/release/launcher.exe

Этот файл можно копировать на любой компьютер (при наличии WebView2) и запускать без дополнительных установок. Также создаётся установщик NSIS в папке src-tauri/target/release/bundle/nsis/.

## Конфигурация

При первом запуске программа создаёт файл config.json в той же папке, где находится launcher.exe. Вы можете редактировать его вручную или использовать встроенный редактор (режим редактирования – замок в левом нижнем углу). Структура файла:

- password_hash – SHA-256 хеш пароля. Если пусто – пароль не требуется.
- app_name – название приложения, отображается в заголовке окна и в сайдбаре.
- app_logo – символ (эмодзи или буква) для логотипа.
- minimize_on_launch – true/false, сворачивать ли окно лаунчера при запуске программы.
- groups – массив групп, каждая группа имеет:
  - id – уникальный идентификатор (генерируется автоматически).
  - name – отображаемое имя группы.
  - buttons – массив кнопок, каждая кнопка содержит:
    - id – уникальный идентификатор.
    - name – название кнопки.
    - command – команда или полный текст скрипта (может быть многострочным).
    - console – true/false, если true – запускается в консольном окне с паузой.
    - powershell – true/false, если true – скрипт выполняется через PowerShell.
    - icon – эмодзи или символ для отображения на плитке.
    - admin – true/false, запускать с правами администратора (UAC).

Пример файла config.example.json прилагается в репозитории. Вы можете скопировать его и отредактировать под свои нужды.

## Использование

После запуска вы видите список групп слева и плитки с кнопками справа. Нажатие на кнопку в обычном режиме (замок закрыт) запускает соответствующую программу или скрипт.

Чтобы редактировать группы и кнопки, нажмите на замок в левом нижнем углу. Если пароль не установлен – режим включится сразу, иначе потребуется ввести пароль. В режиме редактирования появляются дополнительные элементы управления: кнопки для добавления/удаления групп и кнопок, крестики удаления на плитках, стрелки для перемещения, а также кнопка дублирования.

В правом верхнем углу есть поле поиска – оно фильтрует кнопки по названию и команде по всем группам одновременно.

Настройки приложения (название, логотип, поведение при запуске) доступны по кнопке с шестерёнкой в сайдбаре. Там же находятся кнопки для экспорта и импорта конфигурации.
